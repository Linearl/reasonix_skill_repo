# 安装指南

本仓库技能为**自包含目录**（`SKILL.md` + 配套脚本/参考文档），复制即用，无框架依赖。支持 Reasonix、Claude Code 等遵循 Agent Skills 约定的客户端。

## 1. 安装位置

### Reasonix（推荐）

用户级技能目录（所有项目可用）：

| 系统 | 路径 |
|------|------|
| Windows | `%APPDATA%\reasonix\skills\` |
| Linux / macOS | `~/.reasonix/skills/`（或 `~/.config/reasonix/skills/`） |

```bash
# Windows（PowerShell）
Copy-Item -Recurse skills\* $env:APPDATA\reasonix\skills\

# Linux / macOS
cp -r skills/* ~/.reasonix/skills/
```

项目级安装（仅当前项目可用）：复制到项目根 `.reasonix/skills/`。

### Claude Code

```bash
cp -r skills/* ~/.claude/skills/
```

## 2. 验证安装

1. 重启客户端（技能索引在启动时加载）。
2. 输入 `/` 查看命令列表，或直接提问触发技能（见 README「验证安装」表）。
3. 部分技能首次使用需安装 Python 依赖：

| 技能 | 依赖 | 安装 |
|------|------|------|
| book-to-skill | Python 3.9+，部分格式需 Calibre | 见其 SKILL.md |
| image-ocr-to-docs | paddleocr + paddlepaddle + Pillow | `pip install paddleocr paddlepaddle Pillow` |
| onenote-to-obsidian | OneNote 桌面版（Windows COM） | 无需 pip，需要本机装有 OneNote |

## 3. 更新技能

技能会随使用沉淀改进。更新 = **直接覆盖对应目录**：

```bash
Copy-Item -Recurse skills\patent-search $env:APPDATA\reasonix\skills\ -Force
```

覆盖不影响已保存的会话历史；重启客户端后生效。

## 4. 排障

| 现象 | 处理 |
|------|------|
| 技能未出现在索引 | 确认目录名与 `SKILL.md` 的 `name` 字段一致、文件为 UTF-8 编码 |
| 技能触发了但行为异常 | 检查是否有同名旧技能目录冲突（用户级 vs 项目级，项目级优先） |
| 脚本报 Python 模块缺失 | 按上表安装依赖；确认用的是技能文档指定的 Python 环境 |
| onenote-to-obsidian 报"库没有注册" | OneNote COM 类型库注册损坏，需管理员注册（详见技能 SKILL.md） |

## 5. 卸载

删除对应技能目录即可，无注册表/配置文件残留。
