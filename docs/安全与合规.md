# 安全与合规说明

本仓库技能涉及凭据、公司账号、网络抓取与本地数据处理，使用前请阅读本节。

## 1. 凭据管理（强制）

- **任何技能配置的账号、密钥、token 一律不提交到本仓库**（.gitignore 已排除 `.env`，但请自觉遵守）。
- **patent-search**：innojoy 登录凭据按 SKILL.md 指定的方式注入（环境变量/本地配置），仅存在于使用者的本机环境。
- **web-scraping**：CDP 复用的是本机 Chrome 的登录态（cookie 在浏览器 profile 中），脚本不得导出/保存 cookie 文件；临时 cookie 文件用完即删。
- **MediaCrawler 等参考项目**：其 `.env` 含真实凭据，克隆后复制 `.env.example` 自行配置，**禁止将 `.env` 推送到任何仓库**。

## 2. 公司账号边界

- patent-search 使用公司 innojoy 账号，仅限**公司网络环境**与**授权检索用途**。
- 不要在个人仓库/公开讨论中透露检索的客户、技术方向等敏感信息。

## 3. 网页抓取合规

- 遵守目标站点的**服务条款、robots.txt 与所在地区法律法规**。
- 控制抓取频率，合理应对限流（指数退避），不进行破坏性并发抓取。
- 仅抓取你有权访问的内容（自有账号、公开资料）；登录态复用仅限自有账号。
- 抓取内容用于个人学习/研究，不重新发布受版权保护的内容。

## 4. 数据隐私

- **image-ocr-to-docs** 为纯本地推理（PaddleOCR），图片与识别结果不出内网；但请勿将含敏感信息的截图提交到仓库。
- **onenote-to-obsidian** 解析本地 .one 文件，产物直接进入本地 vault；导入前确认目标 vault 非公开同步目录（如公开网盘）。
- 技能处理产生的中间文件（帧目录、临时导出、缓存）使用后清理，或在 .gitignore 中排除。

## 5. 技能内容风险

- 技能是**提示词 + 脚本**，会指导 agent 执行命令。使用前阅读 `SKILL.md` 中标注的 ⚠️ 事项；高风险操作（删除、覆盖、部署、网络请求）建议先审查脚本。
- 第三方技能（book-to-skill、MediaCrawler 引用）版权归各自作者，使用遵循其 LICENSE。
